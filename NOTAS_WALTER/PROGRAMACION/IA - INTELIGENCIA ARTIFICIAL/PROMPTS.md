# Desarrollo de un prompt
La idea es no preguntar sin tener el conocimiento, vamos a limtar el prompt en 3 fases o mejor dicho 3 divisiones:

1. Inicio
2. Desarrollo /nudo
3. cierre desenlace




# INICIO
- <mark class="naranja">Definimos el rol </mark>de la IA (quien es, o que rol debe de asumir para desarrollar, en codigo, analisis etc)
	- <strong class="rosa-encendido">ejemplo </strong>--> <strong class="rosa-encendido">Actua como un desarrollador senior</strong>
- <mark class="verde">Definimos el contexto</mark> , damos la informacion general, **que se esta haciendo, en que estoy trabajando**


# DESARROLLO
- Detallamos la tarea especifica (Que tiene que hacer?)
- Establecemos los limites (*que debe de hacer la IA y que no debe de hacer*)
- Mencionar que debe incluir y que no debe incluir. ✅



# CIERRE / DESENLACE
- Como quiero ver la respuesta.
- <strong class="rosa-encendido">ejemplo</strong> --> entregame la respuesta en una tabla / un bloque de codigo / un lista enumerada


****

# Como hacer un prompt correcto?

1. Primera Verificacion del buen prompt
	- Claridad
	- concrecion
	- especialidad
	- Rol

*Dir exactamente que es lo que quieres*


2. Mantener un contexto claro, no omitirlo como tal ✅
