## GPT Personalizado - Pasos para construccion


<mark class="naranja">NOTA</mark>
*Es parecido al entrenamiento de modelos IA*

<mark class="verde">PASOS</mark>
1. Definir el proposito y los casos de uso
2. Recopilacion de datos importantes.
3. Estructurar los datos para el entrenamiento.
4. Elegir tus herramientas.
5. Definir criterior de analisis.
6. Ajustar y aprobar.
7. Desplegar y automatizar.



****
## 1. DEFINIR EL PROPOSITO Y LOS CASOS DE USO

Necesito decirle que necesito que este logre.

- Darle atencion a las tareas que son repetitivas, que consuman mucho tiempo o requieren respuestas consistentes.

1. <mark class="verde"> IDENTIFICACION DE TAREAS ESPECIFICAS</mark>
2. <mark class="verde">IDENTIFICAR LA INFORMACION PARA CADA CASO EN ESPECIFICO</mark>.

Para la identificacion, tenemos ejemplos como:

- *Preguntas comunes --> cargar boletines de soportes anteriores o documentos de preguntas frecuentes.*

3. <mark class="verde">DEFINIR LOS RESULTADOS ESPERADOS</mark>
Tengo que establecer el formato donde se ajuste mas mis respuestas
- resumen breve
- instrucciones paso a paso



**** 
## 2. RECOPILAR DATOS RELEVANTES

La idea es recuperar datos de alta calidad.

1. <strong class="rosa-encendido">USAR FUENTES INTERNAS</strong>

- Documentos que yo tenga para la alimentacion de las respuestas.
- 
1. <strong class="rosa-encendido">USAR FUENTES EXTERNAS</strong>
Para la complementacion de informacion de fuentes publicas.

2. <strong class="rosa-encendido">INCLUIR UNA VARIEDAD DE EJEMPLO</strong>
- cubrir varios escenarios.
- diversas situaciones.
- incluir varios casos de soporte  como **preguntas de configuracion**


4. <strong class="rosa-encendido">VERIFICACION DE LA CALIDAD DE LOS DATOS</strong>


****
## ESTRUCTURAR LOS DATOS PARA EL ENTRENAMIENTO

Organizar los datos de manera efetiva
- establecer entradas y salidas claras.


1. <mark class="verde">ORGANIZAR LOS DATOS COMO PARES DE ENTRADA - SALIDA</mark>
ejemplo, tenemos una entrada "*como restablezco mi password*"
tendriamos nosotros como salida  "*Instrucciones para reestablecer correctamente la password de una forma correcta***"



2. <mark class="verde">ETIQUETAR LOS DATOS POR CATEGORIA</mark>
La idae es manejarlos por grupos -- categorias.


- configuracion de cuenta
- solucion de problemas
- facturacion

2. PRIORIZAR QUE DATOS SON MAS IMPORTANTES
3. <mark class="naranja">ASEGURAR LA ALTA CALIDAD DE LOS DATOS</mark>
