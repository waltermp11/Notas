# PRINCIPIOS DE ACCESIBILIDAD - UI ( USER INTERFACE)

- La idea es ser inclusivos con las personas.
- Que no hayan brechas

1. **Contraste**
	- texto legible en cualquier pantalla
	- Gris claro sobre blanco


2. **Jerarquia Visual**
	- Tamaño y espacio guian la lectura.
	- No puede tener con el mismo peso visual


3. **Etiquetas de Formulario**
	- La idea es que  no se estresen los usuarios al desarrollarlos.
	- Placeholder que desaparece al escribir.


4. **No depender solo del color**
