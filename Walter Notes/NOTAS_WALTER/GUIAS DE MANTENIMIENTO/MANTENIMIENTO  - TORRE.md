# GUIA MANTENIMIENTO  - PC DE MESA

## PRIMEROS PASOS IMPORTANTES PARA EL DESARROLLO DE MANTENIMIENTO

- Apagar el PC 
- Apagar la fuente, la cantidad de watts.
- Desconectar del toma corriente.
- Verificacion de que no haya nada prendido para proceder a mover el equipo.

## <mark class="naranja">
PASOS PARA EL MANTENIMIENTO PREVENTIVO</mark>

<mark class="verde">NOTA</mark> 
*Los mantenimientos de Pc normalmente son cada 6 meses, depende de como este el nivel de polvo*



### <mark class="naranja">HERRAMIENTAS PARA EL MANTENIMIENTOS</mark>
- Destornillador
- Multimetro
- Brocha
- Soplador o secador (*SOLAMENTE AIRE FRIO*)
- Linterna

<mark class="verde">La idea es reconoces todos los componentes:</mark>

1. tarjeta Grafica --> soplar
2. Memoria ram --> soplar y limpiar con borrador
3. Procesador
4. almacenamiento
5. refrigeracion


### <mark class="verde">RECOMENDACIONES</mark>

- usar limpia contactos, en caso de ser muy mojado, se requiere soplar --> <mark class="naranja">SOLO CON AIRE FRIO, TAMBIEN OJALA QUE NO FUERA CON ESTATICA.</mark>
- Para el mantenimiento tener una brocha para la limpieza de una manera superficial.
